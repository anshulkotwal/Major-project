# Contributing to Personalized Learning Assistant

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/personalized-learning-assistant.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes
6. Commit: `git commit -m "Add your feature"`
7. Push: `git push origin feature/your-feature-name`
8. Create a Pull Request

## Development Guidelines

### Code Style

- Use ES6+ JavaScript features
- Follow React best practices
- Use functional components with hooks
- Keep components small and focused
- Write meaningful variable and function names

### Frontend

- Use Tailwind CSS for styling
- Follow the existing component structure
- Ensure responsive design
- Add animations where appropriate
- Test on multiple browsers

### Backend

- Follow RESTful API conventions
- Add proper error handling
- Validate all inputs
- Write clear API documentation
- Use async/await for asynchronous code

### Database

- Use Mongoose schemas
- Add proper indexes
- Validate data at schema level
- Use meaningful collection names

## Testing

- Test all new features
- Ensure existing tests pass
- Add tests for bug fixes
- Test edge cases

## Commit Messages

Use clear and descriptive commit messages:

- `feat: Add AI chat feature`
- `fix: Resolve authentication bug`
- `docs: Update API documentation`
- `style: Format code with prettier`
- `refactor: Improve performance analytics`
- `test: Add tests for recommendations`

## Pull Request Process

1. Update documentation if needed
2. Add tests for new features
3. Ensure all tests pass
4. Update README.md if needed
5. Request review from maintainers

## Code Review

- Be respectful and constructive
- Explain your suggestions
- Be open to feedback
- Focus on code quality

## Feature Requests

- Open an issue first
- Describe the feature clearly
- Explain the use case
- Discuss implementation approach

## Bug Reports

Include:
- Clear description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable
- Environment details

## Questions?

Feel free to open an issue for any questions or clarifications.

Thank you for contributing!
